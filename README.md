# E-Commerce Customer Insights & Sales Performance Analysis

## Overview
This repository contains the solution for **Data Analytics Internship — Assignment 2** focusing on Python basics, NumPy operations, Pandas data manipulation, and visualization using Matplotlib and Seaborn.

## Key Objectives
- **Python & NumPy Operations:** Data types, arithmetic/logical operators, array statistics, reshaping, and Month-over-Month (MoM) growth calculations.
- **Data Cleaning & Merging:** Handling missing values in customer records and inner joining with purchase transaction data.
- **Exploratory Data Analysis:** Groupby aggregations for total sales by city, average spend by gender, and top-performing customers.
- **Data Visualization:** Generated bar charts, pie charts, and line plots to track spending patterns over time.

## Key Findings
- **Highest Revenue City:** Mumbai (INR 73,000), driven by high-ticket consumer electronics.
- **Top Customer:** Aarav (C01) with a total spend of INR 73,000 across multiple orders.
- **AOV by Gender:** Male transactions averaged INR 15,692.71 due to tech purchases compared to INR 2,833.00 for female transactions.

## Technologies Used
- Python 3.x
- NumPy
- Pandas
- Matplotlib & Seaborn
